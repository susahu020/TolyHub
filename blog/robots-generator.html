🤖 Robots.txt Generator: Control How Search Engines Crawl Your Site

The robots.txt file tells search engine crawlers which parts of your site they can and cannot access — getting it wrong can accidentally block your entire site from search results.

What robots.txt Does

Placed at the root of your domain (e.g., yoursite.com/robots.txt), this file uses simple directives to allow or disallow crawler access to specific paths, and can point crawlers to your XML sitemap.

How to Use the Generator

Specify which user agents (crawlers) you want to target, which paths to allow or disallow, and your sitemap URL. The tool generates a properly formatted robots.txt file ready to upload to your site's root directory.

Common Mistakes to Avoid

A common error is accidentally disallowing '/' (the entire site), which blocks all crawling. Always test your robots.txt with Google Search Console's robots.txt tester before deploying.

Frequently Asked Questions

Does robots.txt prevent pages from being indexed?

Not necessarily — a disallowed page can sometimes still appear in search results without a description if it's linked from elsewhere. Use a 'noindex' meta tag for guaranteed exclusion.

Where must robots.txt be placed?

It must be at the root of your domain, e.g., https://example.com/robots.txt — it won't work in a subdirectory.
